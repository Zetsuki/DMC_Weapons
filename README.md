# Devil May Cry Weapons Mod (WIP)

This Minecraft mod adds weapons from the *Devil May Cry* series in the game. The weapons included are:

- **Rebellion (Work in Progress)**
- **Yamato (Work in Progress)**

## Installation

1. Download and install [Minecraft Forge](https://files.minecraftforge.net/).
2. Download the mod `.jar`.
3. Place the `.jar` file in your Minecraft `mods` folder.
4. Launch the game with the Forge profile.
5. Enjoy !
